# Nebula Particles 3D

[https://img.shields.io/badge/365%20Days%20Challenge-Day%202%2F365-8B5CF6?style=for-the-badge]
[https://img.shields.io/badge/Stack-Three.js%20%7C%20WebGL%20%7C%20Tailwind%20CSS-06B6D4?style=for-the-badge]

An interactive **3D WebGL particle morphing playground** powered by Three.js. Watch 15,000 glowing particles smoothly transform between cosmic and mathematical 3D shapes in real time.

## Live Demo
👉 **[Explore Nebula Particles 3D Live](https://a1n2a3s6.github.io/nebula-particles-3d/)**

## Features
- **5 Morphing 3D Formations:** Smoothly transition between Spiral Galaxy, DNA Double Helix, Saturn & Rings, Torus Knot, and Cosmic Sphere.
- **Interactive Camera:** Full 360° orbit, zoom, and smooth damping controls.
- **Color Palettes & Tuning:** Switch between 4 curated palettes and adjust particle size, rotation speed, or enable Auto-Morph.
- **Zen Mode:** Toggle the floating HUD off for a pure full-screen visual experience.
- **Zero Build Setup:** Single-file static HTML ready for instant GitHub Pages hosting.

## Built With
- HTML5 & WebGL
- Three.js (ES Modules CDN)
- Tailwind CSS (CDN)
